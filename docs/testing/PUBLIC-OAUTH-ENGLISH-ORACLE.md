# Public OAuth English oracle

`public-oauth-oracle.en.json` is the project-owned wording oracle for launch point 1.
It was written independently from production emitters for the operator-approved transition from
Romanian public entry copy to English public entry copy. The source request is quoted in the
oracle, and the baseline application revision is recorded there.

The external Romanian oracle remains the immutable transition source. Its SHA-256 digest is
recorded in the English oracle and checked by the public access boundary test, so the language
transition cannot silently rewrite its provenance.

The oracle fixes the provider scope, permission capability, application behavior, mutation
behavior, English language metadata, and required or forbidden wording for every point-one public
state. Structural snapshots continue to fix the complete rendered output. The connect page keeps
its point-two page copy; only the shared OAuth clauses rendered there transition in point 1.
